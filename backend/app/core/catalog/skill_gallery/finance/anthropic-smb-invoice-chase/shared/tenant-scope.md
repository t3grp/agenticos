# Tenant and engagement scope

A connected document store, mailbox, ledger or processor is not automatically the right client account. Confirm the authorized client, legal entity and target account/folder before the first substantive read. A display name or domain is supporting evidence, not a conclusive account identifier.

Use a named engagement collection, source account, folder, file or mailbox and scoped search terms. Do not browse unrelated client stores or use recent-file discovery to replace missing accounting inputs. The accountant's own account can legitimately hold many clients; account ownership alone is not engagement authorization.

If the account or document population does not match the engagement, ask for the missing scope decision or a scoped upload before reading further. Do not substitute a different tenant because its connector works. If a mismatch is noticed after a read, exclude that content from calculations and outputs and report the scope problem without reproducing unrelated confidential data.

Carry entity, account, period and currency identifiers into every source citation so later skills do not accidentally combine clients. See `connector-neutrality.md` for overlapping source-of-record handling.
