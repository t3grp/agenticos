# Output format and review handoff

Use the user's requested format and any engagement-specific preference already supplied. Do not assume a Cowork memory folder, an onboarding skill or a shared editable profile exists in t3OS. The immutable bundled resource is guidance; client preferences belong in authorized engagement context.

| Requested format | Preparation output |
|---|---|
| Chat / plain text | Complete reviewable tables, formulas, citations and draft text in the response. |
| HTML | A local, self-contained review artifact when a configured runtime can create it. Use `artifact-style.md`. |
| DOCX / PDF | A local review document using available tools; inspect the rendered result where possible. |
| XLSX | A calculation workbook with evidence, assumptions, formulas/control totals and reviewer flags. |
| Markdown | A readable local text file when requested or useful. |
| Notion / Canva | Prepared transferable content for a separate authorized publishing workflow; no page or design is created by this pack. |

A requested import/file format may impose fields, tabs or validation rules. Verify those before calling a file import-ready. If the runtime cannot create the requested format, deliver the complete substantive content and explain the file limitation; do not claim a file or external page exists.

Do not create several equivalent artifacts by default. Put the key result in chat and provide the complete review package in the chosen available format. Preserve the client/entity/period/currency, source cut-off, draft status and reviewer questions regardless of format.
