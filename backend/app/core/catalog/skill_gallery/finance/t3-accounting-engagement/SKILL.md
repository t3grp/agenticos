# Accounting engagement and workpaper context

Use this shared procedure before preparing financial work and when reviewing another agent's result. It records the facts a reusable accounting agent must not guess and makes each result traceable to source evidence.

## Establish the engagement

Read the selected engagement or project first. Record client name and identifier; legal entity and source-system account; reporting period and cut-off; accounting basis; functional and presentation currency; FX source/date; applicable reporting framework; tax jurisdiction; task objective; reviewer; and intended audience. Confirm a source of record where several ledgers or copies exist. Ask only for fields material to the requested work that cannot be established from authorized evidence. An unknown field stays unknown; an accounting firm's location does not decide a client's framework or tax jurisdiction.

## Keep the evidence register

| Evidence ID | Client/entity | Source and locator | As-of / period | Filters and completeness | Currency / unit | Retrieved or supplied | Use |
|---|---|---|---|---|---|---|---|
| E-001 | Confirmed scope | System report or file with page/row | Explicit cut-off | Entity, date range, status, pagination | ISO code and unit | Timestamp | Balance or conclusion supported |

Give every proposed entry, reconciliation difference, calculation and material conclusion one or more evidence IDs. Capture source totals and counts before transforming data. Keep copied data, computed values and judgment separate. Preserve the original file and reconcile duplicate exports before merging them. An amount can be zero only when the source actually supplies zero or a supported calculation gives zero; an absent account/report is not zero.

## Build a reviewable workpaper

State objective, scope, preparer role, preparation time and review status. Show the source population, transformation rules, formulas, rounding, signs, currencies, and opening-to-closing roll-forward. Tie statements to the trial balance, subledgers to the control account, and cash to bank evidence when those sources are available. Keep unreconciled items in an exception register with owner, amount, reason, evidence and required next step. Do not conceal exceptions by netting currencies, creating plugs, assuming a prior-period balance or inventing missing transactions.

| Proposal / exception | Evidence | Calculation or finding | Uncertainty | Reviewer action | Status |
|---|---|---|---|---|---|
| Identified item | E-001 and row/page | Reproducible reasoning | Named missing input | Specific review question | Draft / awaiting evidence / reviewed |

## Review and handoff

Check cross-footing, period boundaries, duplicate keys, currency separation, units, evidence links, population completeness and unsupported claims. State which checks ran and their results. A drafted journal is not posted; an import file is not imported; a proposed payment is not paid; a tax workpaper is not filed. No automated posting, payment, filing, certification or message sending is authorized by this skill. Route the result to the engagement's actual reviewer without representing the agent as a licensed accountant or auditor.

## Tools and sources

Confirm current primary authority before any jurisdiction-dependent tax or reporting conclusion; identify the authority, effective date and uncertainty.
